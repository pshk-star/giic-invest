# P1.8 — Validación predictiva y calibración de confianza

**Estado:** backtest PIT + rúbrica de confianza, con pruebas (+21; 391 backend verde) y CI.
**Producción intacta** (Fair Value productivo y Advisor 2.2 sin cambios). **No** se calibra a mercado.
Prioridad cumplida: **evidencia predictiva real por encima de complejidad**.

Tres categorías, separadas explícitamente:
- **Validación histórica real:** el backtest PIT de §1-§3 (datos reportados con fecha, sin look-ahead).
- **Simulación retrospectiva:** NO realizada para el consenso (B) — ver §0; sería look-ahead.
- **Pruebas técnicas:** 21 tests unitarios de los modelos, métricas y rúbrica.

---

## 0. Qué puede validarse y qué no

**El consenso (modelo B) NO es backtesteable.** EODHD **no versiona el consenso histórico** (no hay
*vintages*: `Earnings.Trend` es una foto actual + registros por período, sin la fecha en que cada
estimación estuvo disponible). Usar el consenso actual como si hubiera existido en el pasado sería
look-ahead, que está prohibido. **B solo puede validarse PROSPECTIVAMENTE** con los `pit_snapshots`
que GIIC acumula desde P1.7 (se requiere track record futuro).

**Sí** se valida con PIT real lo que usa solo estados financieros reportados (con fecha de publicación):
**A** (GIIC sin consenso), **C** (reinversión/capital invertido), **D** (baseline histórico).

## 1. Backtest PIT — muestra y resultados

**Muestra:** 45 empresas, **10.413 puntos** (empresa × año base × horizonte), horizontes 1/2/3 años.
Series anuales EODHD; año base con ≥4 años previos y resultado reportado disponible a ti+h; proyección
con datos ≤ ti únicamente. Convención: FY disponible a FY_end+90d (la comparación es reportado-vs-
reportado, que ya respeta ti).

**Error de proyección (mediana del |error relativo|), por modelo y horizonte:**

| modelo | ingresos h1 | h2 | h3 | margen EBIT h1/h2/h3 | FCFF h1/h2/h3 | sesgo ingresos |
|---|--:|--:|--:|--:|--:|--:|
| **A** GIIC | **6,2%** | 11,9% | 15,1% | 2,7 / 3,5 / 4,0% | 54 / 56 / 58% | ≈0 (insesgado) |
| **D** baseline | **6,0%** | 11,7% | 15,7% | 2,7 / 3,5 / 4,0% | 50 / 54 / 56% | ≈0 |
| **C** reinv×ROIC | 9,5% | 17,7% | 25,7% | 2,0 / 2,7 / 3,0% | 44 / 48 / 54% | −1 a −4% (subestima) |

**Lectura (evidencia, no opinión):**
- **Los ingresos son predecibles a 1 año** (~6% de error, insesgado) y se degradan a ~15% a 3 años.
- **El margen EBIT es muy predecible** (~3-4%): mantener el promedio móvil funciona.
- **El FCFF NO es predecible** (~50% de error en todos los modelos/horizontes): la reinversión y el
  capital de trabajo son demasiado volátiles. **Esto limita la confianza de cualquier Fair Value por
  FCFF como cifra puntual.**

## 2. Comparación de modelos (sin elegir en los períodos de ajuste)

Reglas **a-priori** (no se ajustaron parámetros a los períodos de evaluación), así que la comparación
es limpia:
- **D (baseline histórico) iguala a A (GIIC)** en ingresos (6,0% vs 6,2% a h1). La sofisticación de A
  no aporta sobre el crecimiento histórico normalizado.
- **C (reinversión×ROIC) es PEOR** (9,5% a h1, 25,7% a h3) y **subestima** el crecimiento. El modelo
  fundamental de crecimiento **no debe usarse** para estas empresas: añade error, no precisión.
- **Conclusión:** el baseline simple es un benchmark fuerte; A es defendible pero no superior; C se
  descarta.

**Por empresa (modelo A, ingresos, agregado 1-3a):** más fáciles (MAE<7%): WMT 3,5%, JNJ 4,7%, SPGI
5,0%, MCD 5,4%, COST 6,5%. Más difíciles (MAE>20%): MU 30,8%, TSLA 30,1% (sesgo −28%), QCOM 22,7%,
AMAT 22,4%, AMD 21,4%. **Las 5 del MVP están entre las difíciles** (semis/crecimiento): NVDA 20,3%,
ASML 21,4%, META 15,0%, TSM 13,4%, NFLX 10,4%.

## 3. Calibración de incertidumbre

Intervalos construidos desde la distribución de errores OOS; cobertura medida por **jackknife**
(leave-one-out). Resultado: cobertura ≈ nominal (50/80/90 → 0,50/0,80/0,90) para ingresos y margen.
**Caveat honesto:** esto mide la **consistencia interna** del intervalo empírico, **no** la calibración
predictiva **hacia adelante** (que exige un holdout temporal virgen = el track record futuro). Para
**FCFF** los intervalos son tan anchos (~±50%) que **no son útiles** para decisión. Se separan:
- **Incertidumbre de ingresos/margen:** acotada y usable como banda de error histórica.
- **Incertidumbre de FCFF:** grande; no se presenta como intervalo calibrado útil.
- **Incertidumbre adicional del Fair Value (WACC/terminal):** es la de P1.7.4 (sensibilidad +
  peso terminal), separada de la de los flujos.

## 4. Confianza de GIIC (rúbrica basada en evidencia)

Cinco criterios; **'alta' exige evidencia** (error OOS medido y bajo + corroboración + baja
concentración terminal), no se asigna por pasar controles. Resultado para las 5 (nivel = peor criterio):

| | datos | error OOS (ingresos) | corroboración | sensibilidad | concentración terminal | **confianza** |
|---|:--|:--|:--|:--|:--|:--|
| NVDA | alta | **baja** (20,3%) | media (>guidance) | alta | alta (57%) | **baja** |
| META | alta | media (15,0%) | alta | alta | media (63%) | **media** |
| NFLX | alta | media (10,4%) | alta | alta | media (63%) | **media** |
| TSM | alta | media (13,4%) | media (>guidance) | alta | media (63%) | **media** |
| ASML | alta | **baja** (21,4%) | alta | alta | media (63%) | **baja** |

**Ninguna de las 5 alcanza confianza alta.** El cuello de botella es el **error histórico de ingresos**
(semis/crecimiento son difíciles de proyectar) y, de fondo, la **imposibilidad de proyectar FCFF**.

## 5. Recomendación: producción / más evidencia / experimental

**Listo para producción (como está):** nada nuevo. Se mantiene el DCF productivo y Advisor 2.2 **sin
cambios** — es lo correcto dado que ningún componente prospectivo alcanza confianza alta.

**Usable con reservas (confianza media, como INSUMO con banda de error, no como verdad puntual):**
- Proyección de **ingresos a 1-2 años** (modelo A o D, indistinto) para META/NFLX/TSM.
- Proyección de **margen EBIT** (promedio móvil): robusta en general.

**Requiere más evidencia (no usar aún para decisiones):**
- **Consenso (B):** solo validación prospectiva; acumular `pit_snapshots` y medir track record.
- **NVDA y ASML:** error de ingresos >20%; confianza baja.

**Mantener experimental / descartar:**
- **Fair Value por FCFF como cifra puntual:** el FCFF tiene ~50% de error → no es base de decisión;
  seguir usándolo solo como marco de escenarios, no como número.
- **Modelo C (reinversión×ROIC):** peor que el baseline → **descartar** para estas empresas.

**Principio confirmado:** el baseline simple es difícil de batir; la complejidad (C, consenso mal
leído) ha añadido error, no valor. GIIC debe reportar **rangos con confianza explícita**, no Fair
Values puntuales de falsa precisión.
