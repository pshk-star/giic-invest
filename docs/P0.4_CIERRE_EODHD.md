## 4. Datos que siguen faltando (para Fair Value)

- **Flujos interinos de un trimestre o YTD NO son aptos** para valoración directa (se necesita TTM o
  anual). Fair Value deberá construir TTM a partir de 4 trimestres individuales verificados, nunca de
  un YTD (p. ej. OCF de ASML es YTD).
- **EPS de EODHD** es de base ambigua → nunca apto para valoración (las diluidas ponderadas vienen solo
  de EDGAR).
- **net_debt/total_debt** de EODHD queda `parcial` (composición a conciliar); net_debt de valoración
  sigue de EDGAR.
- Algunos internacionales dependen de **EODHD anual `parcial`** (no verificado contra oficial del mismo
  período) — elegible por período, pero requiere control adicional en Fair Value.
- **Research on-demand** aún no implementado (empresas fuera del universo diario se enriquecen al abrirlas).

## 7. Operación diaria

- **Cron habilitado enriquecido** (`scan.yml`, schedule → `GIIC_EODHD_ENRICH=1`). Dispatch manual con
  input `enrich`.
- **Carry-forward en producción confirmado:** un scan EDGAR-only preserva los bloques (23 arrastrados en
  la prueba; internacionales intactos), sin tocar EDGAR ni las 309.
- **Rollback (dos mecanismos):** (a) kill-switch instantáneo — variable de repo `GIIC_EODHD_DISABLE=1`
  (Settings → Variables), apaga el enriquecimiento sin commit y sin borrar lo persistido; (b) restaurar
  payloads desde respaldo si hubiera inconsistencia material.
- **Error material corregido** durante la activación: `UnboundLocalError` en la ruta EDGAR-only (import
  redundante de `AssetClass`); corregido con prueba de regresión; el cron usa el código corregido.

## 8. Riesgos pendientes para Fair Value

1. **Elegible ≠ verificado:** `valuation_eligible=true` indica período/definición apto, no calidad
   verificada. Fair Value debe aplicar sus propios controles (quality_state, conciliación) y no tomar
   `parcial` como insumo confiable automático.
2. **TTM no disponible listo:** construir TTM solo de trimestres individuales verificados; excluir YTD e
   indeterminados (ASML OCF/CAPEX/FCF).
3. **Bancos:** no aplicar DCF industrial (JPM); modelos específicos.
4. **Internacionales:** anuales EODHD `parcial` donde EDGAR no cubre el período — usar con control.
5. **Cobertura de Research:** on-demand pendiente (no bloquea Fair Value del universo actual).
