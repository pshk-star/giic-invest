## 1. Metodología

### A — Crecimiento por evidencia (reemplaza el tope plano del 18%)
1. **g1 fundamentado, sin tope duro:** se parte del **CAGR de ingresos real (sin acotar)** y se aplica **compresión cóncava asintótica** (umbral 20%, escala 15%): admite >18% con evidencia y comprime suavemente los extremos (NVDA CAGR 67% → g1 **34%**), sin un cap plano ni un "30% arbitrario".
2. **Desaceleración explícita en dos fases** (no extrapola el CAGR 10 años): años 1-5 el crecimiento declina de g1 a **8%** (mid-cycle), años 6-10 de 8% a terminal 2,5%. Para nombres de bajo crecimiento (g1 ≤ 10%) se usa el **fade lineal V1 sin cambio** → las maduras no se inflan.
3. **Consistencia FCF-ingresos-márgenes-reinversión:** el crecimiento se aplica al **FCF** (ya neto de CAPEX y reinversión), manteniendo el margen implícito constante; no se readid CAPEX (eso sería C). Así los costos de crecimiento siguen con sus beneficios.
4. Escenarios conservador / base / optimista (g1, mid-cycle, terminal y tasa).

### B — Normalización robusta (reemplaza la media histórica fija)
Para cada empresa se calculan **cuatro** candidatos sobre la ventana real (últimas 4 filas con ingresos): **media, mediana, ponderación reciente, margen actual**. Se **selecciona por estabilidad**, no por el FV más alto:
- CV < 0,15 (estable) → **media**.
- |correlación año-margen| > 0,6 (tendencia clara) → **ponderación reciente**.
- Volátil sin tendencia / outlier → **mediana**.
- **Guarda:** el margen elegido nunca supera el máximo observado (ni es negativo).

### Convención de flujo (tu punto 5)
- `OCF − CAPEX` sigue **etiquetado como aproximación a FCFE**, no se reetiqueta como FCFE exacto.
- **Deuda neta:** no se resta (servicio ya en el FCFE); se reporta `deuda neta / equity` como **bandera de confianza**. Materiales: PEP +32%, KO +24%, WMT +12%, JNJ +7% (en los 5 objetivos es ≤3%).
- **SBC y dilución futura:** se usan acciones **diluidas** (capta dilución realizada). El SBC va readido en OCF (infla algo el FCF) y la dilución futura por SBC **no** se modela con el dato disponible → **limitación documentada**, no corregida (coherente con C/D pospuestos).
