## 1. Metodología documentada y fórmulas

**Método principal (no financieras):** DCF determinístico sobre **FCF = OCF − CAPEX** (de la historia anual EDGAR), en **moneda de reporte**. Un único flujo y una única tasa (no mezcla FCFF con FCFE).

- **FCF base normalizado** = margen FCF medio de los últimos ≤4 años × ingresos del último ejercicio (suaviza la volatilidad de CAPEX sin perder escala). Alternativa: mediana de FCF a 3 años.
- **Proyección explícita**: horizonte de 10 años; el crecimiento decae linealmente de `g1` a `g_terminal`.
  `FCF_t = FCF_base · Π(1+g_s)`, con `g_s` interpolado.
- **Tasa de descuento** (coste de capital, fundamentada): `r = rf + β·ERP = 4.0% + 1.1·5.0% = 9.5%` base.
- **Valor terminal (Gordon)**: `TV = FCF_N·(1+g_t)/(r − g_t)`, con `g_t` conservador (2.0–3.0%).
- **Puente a valor por acción**: `EV = Σ FCF_t/(1+r)^t + TV/(1+r)^N` → `Equity = EV − deuda neta` (deuda neta < 0 ⇒ caja neta suma) → `valor/acción = Equity / acciones diluidas`.
- **Guardas (no se fuerza un Fair Value)**: si faltan ≥3 años de FCF, si el FCF base ≤ 0, o si no hay acciones diluidas → **"Valoración no disponible"** con el motivo. No se usan EPS ambiguos, campos en cuarentena, YTD como TTM ni interinos `parcial`.

**Múltiplos (complementarios, no sustitutos):** P/E (anual) y FCF yield se mantienen en un panel aparte de comparables de sector; nunca reemplazan al DCF.

## 6. Cobertura real del universo

- El Fair Value se calcula **a demanda en Research** para cualquier empresa con payload (universo diario de 106 + enriquecimiento on-demand). No añade batch ni infraestructura.
- **Con DCF**: no financieras con ≥3 años de FCF anual, acciones diluidas y FCF base positivo (NVDA, META, TSM, ASML y análogas).
- **Margen vs. precio calculado**: sólo cuando precio y valor comparten moneda (hoy, US doméstico). Internacionales/ADR: valor intrínseco en moneda nativa, margen pendiente de FX fechado.
- **Sin DCF (marcadas no disponible)**: bancos/aseguradoras y cualquier empresa con datos insuficientes (p. ej. JPM).

## 7. Limitaciones pendientes para Advisor 2.0

1. **FX fechado**: para ADR/internacionales falta una tasa de cambio fechada y la relación ADR↔ordinaria para traducir el valor intrínseco a la cotización y calcular el margen. Es el bloqueo principal para "cara/barata" en TSM/ASML.
2. **Financieras**: falta un método defendible (P/TBV o exceso de retorno sobre coste de capital) para bancos/aseguradoras; hoy quedan como no disponibles.
3. **β y tasa por empresa**: la tasa usa β=1.1 genérico; un WACC por empresa (β real, estructura de capital, coste de deuda) afinaría el descuento.
4. **FCFF puro**: el FCF = OCF − CAPEX omite el ajuste de interés después de impuestos; inmaterial para los casos de caja neta validados, relevante para empresas muy apalancadas.
5. **Peso del valor terminal** (~57%): inherente al método; Advisor 2.0 debería ponderar la confianza por ese peso y por la volatilidad del FCF.
6. **Normalización del FCF base**: la media de margen suaviza, pero ciclos de CAPEX intensos (IA) pueden sesgar el base; conviene exponer escenarios de reinversión explícitos.

Base para Advisor 2.0: combinar este Fair Value (margen de seguridad + confianza) con los factores del scanner y el riesgo determinístico, **sin** forzar un precio objetivo donde los datos no lo sostienen.
